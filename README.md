# DataMinig_AhmedTea_Quiz
# Summary of Data Mining Quiz HTML File

This is an **interactive web-based quiz application** for a Data Mining course (Ahmed Tea edition). Here are the key features:

## Core Functionality
- **10 Lectures** covering topics from Data Mining Fundamentals through Web Mining
- **~300+ questions** with multiple-choice format
- **Quiz customization**: Select specific lectures or mix all together, choose question count (10-50 or all), set timer per question, and shuffle/order options
- **Real-time scoring** and progress tracking

## User Interface
- **Chalkboard theme** with vintage styling (chalk dust effects, wooden frame, chalk tray)
- **Three main screens**:
  1. **Home**: Lecture selection and quiz settings
  2. **Quiz**: Question display with options, explanations, timer, and scoring
  3. **Results**: Final grade, statistics, and review functionality

## Technical Features
- **Responsive design** (mobile-friendly)
- **Timer system** with visual warnings when time runs low
- **Progress bar** showing completion percentage
- **Streak tracking** for consecutive correct answers
- **Review mode** showing all answered questions with correct answers highlighted
- **Statistics**: Correct count, wrong count, percentage score, average time per question

## Quiz Features
- Immediate feedback with explanations for each answer
- Color-coded options (green for correct, red for wrong)
- Answer reveal functionality
- Retry and home navigation options

The quiz data is embedded directly in JavaScript with ~300 questions organized by lecture and section, making it a self-contained, offline-capable application.
